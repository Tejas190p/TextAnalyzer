\# Text Analyzer 📝



A beginner-friendly Python command-line tool that analyzes text and reports word counts, character counts, sentence-ending marks, and occurrences of a searched term.



\## Features



\- Count words

\- Count all characters

\- Count characters without ordinary spaces

\- Estimate sentence count using `.`, `!`, and `?`

\- Search for text without case sensitivity

\- Handle empty input



\## Requirements



\- Python 3.10 or newer recommended

\- No external packages required



\## Run the Project



```bash

python main.py

```



\## Concepts Practiced



\- Functions and parameters

\- Strings and string methods

\- Lists and dictionaries

\- `input()` and `print()`

\- Conditional statements

\- `len()`, `sum()`, and `count()`

\- Returning values from functions



\## Limitations



Sentence counting is a basic punctuation-based estimate. Search counts substring occurrences rather than whole-word matches.
